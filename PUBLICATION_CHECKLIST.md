# Before publishing KORDEX publicly

- [ ] Review every file in the repository and confirm you have the right to publish it.
- [ ] Confirm there are no credentials, private telemetry, personal information, or confidential company details.
- [ ] Confirm the intended GitHub repository visibility is **Public**.
- [ ] Decide on a software license before inviting reuse or accepting code contributions. No license is included in this preview.
- [ ] Check that any screenshots do not reveal private data or imply a live robot connection.
- [ ] Do not claim validated failure-prediction accuracy without a documented evaluation supporting that claim.
- [ ] The interface is intended for local use; do not deploy it publicly without security review and appropriate access controls.

This package excludes large/raw datasets and generated session outputs. It is a curated publication candidate, not a guarantee that every research script is independently reproducible without those omitted assets.
